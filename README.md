# Colab Notebooks

This repository contains a collection of Google Colab notebooks for exploring practical AI workflows and experiments.

## Catalog

- [Gemini Omni Capabilities](gemini-omni-capabilities.ipynb) - Generate and edit video with Gemini Omni Flash through the Interactions API: text-to-video, on-screen text, generated audio, and edits chained across turns.
- [Get Started with Chatterbox TTS](get-started-with-ChatterBox-TTS.ipynb) - Run Resemble AI's open-source Chatterbox models (Turbo, Multilingual, and English) for zero-shot voice cloning, paralinguistic tags like `[laugh]`, and speech in 23+ languages.
- [Get Started with Gemini TTS](get-started-with-gemini-TTS.ipynb) - Turn text into single-speaker or multi-speaker audio with the Gemini API, and control style, accent, pace, and tone with prompts.
- [Get Started with Qwen3 TTS](get-started-with-qwen3-TTS.ipynb) - Try Qwen3-TTS: built-in voices, designing a voice from a text description, cloning a voice from 3 seconds of audio, and emotion control across 10 languages.
- [How to Segment Images with Segment Anything 3](how-to-segment-images-with-segment-anything-3.ipynb) - Segment every instance of a concept in an image with SAM 3, prompting with short noun phrases like "striped cat" or with visual examples.
- [How to Segment Videos with Segment Anything 3](how-to-segment-videos-with-segment-anything-3.ipynb) - Segment and track every matching object through a video with SAM 3, keeping each object's identity across frames.
- [Multimodal File Search](multimodal-file-search.ipynb) - Build a multimodal RAG system on the Gemini File Search tool, with page-level citations, cross-modal retrieval of charts, and metadata filters.
- [Needle 3](Needle3.ipynb) - Test Cactus Compute's 35 MB Needle 3 model on CPU for tool calling, structured extraction, refusals, and embeddings, with measured results including where it fails.
